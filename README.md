# Auto Save

Fabric mod for Minecraft 26.2.

## Features
- `$` / `Shift+4` opens the GUI.
- Black GUI.
- Auto Save ON/OFF.
- Windows folder picker.
- Automatic backups every 5 minutes.
- Backup list and restore confirmation.
- Safety backup before restore, then world replacement.
- Safety backup before restore.
- Mod icon via `fabric.mod.json`.

## Build
GitHub Actions uses Java 25 and Gradle to build the mod.
